# 沧海弈局 · OceanGambit

**一款正在开发中的三维海战即时战略（RTS）游戏。**

《沧海弈局》希望让玩家站在舰队指挥官的视角，指挥不同类型的战舰，在动态变化的海上战场中进行战术对抗。

游戏将以舰队调度、航线规划、目标分配与战术决策为核心，同时通过三维舰船模型、弹道模拟与战斗特效，呈现海战的过程。

## 项目特色

**舰队级战术指挥**

游戏计划支持多舰编队、舰船选择、航行指令与自主交战。玩家不必亲自操纵每一门火炮，而是通过指挥舰队影响战局。

**三维海战场景**

基于 OpenSceneGraph 构建三维战场，使用 Triton 渲染海洋，并支持舰船模型、动态相机和战斗效果。

**弹道与火控模拟**

炮弹拥有独立的飞行轨迹，支持重力、空气阻力、射击散布和碰撞检测。火控系统能够根据目标位置计算射击角度，并支持不同弹道模式。

**可扩展的舰船系统**

舰船通过独立的 JSON 配置描述模型、炮塔、炮管、旋转节点与观察视点。系统面向多种舰型设计，支持普通模型节点及 OSG DOF 节点的控制。

## 当前开发状态

项目目前处于**早期可运行原型阶段**。

已实现基础三维海洋场景、舰船加载、炮塔运动、炮弹飞行、舰体与海面碰撞及命中特效，并建立了双舰交战测试场景。

目前还提供舰船跟随视角、望远镜及手动射击功能，主要用于验证舰船控制、弹道和火控系统。

下一阶段将重点推进：

- 多舰型加载与舰船管理
- RTS 战场相机及舰船选择
- 舰队移动与战术指令
- 自动火控与多舰交战
- 二维战术地图

完整的 RTS 玩法仍在开发中。

## 技术栈

- **C++17** — 核心逻辑与战斗模拟
- **Qt 5** — 窗口与交互界面
- **OpenSceneGraph 3.6.5** — 三维场景与模型管理
- **Triton** — 海洋渲染
- **CMake** — 项目构建

项目目前主要在 Windows 环境下开发和测试，依赖相应的图形库、运行时组件及舰船模型资源。

## 开发方向

《沧海弈局》的目标不是让玩家成为一艘战舰的炮手，而是成为整支舰队的指挥官。

我们希望在具有一定物理与战术表现力的海战模拟基础上，让舰船自主执行命令，让玩家将注意力集中在更宏观的战局判断与战术选择上。
